Basic 5G KPIs for anomaly detection

1️⃣ What is an Anomaly in 5G?

In 5G, an anomaly is any behavior that deviates from normal network patterns and may impact QoS, QoE, SLA, or security.

Examples

  • Sudden PRB utilization spike without traffic growth
  • gNB handover failure surge in a specific TA
  • Latency jitter increase in URLLC slice
  • Packet loss only during 특정 hour / cell / device type
  • Control-plane signaling storm (AMF/SMF overload)

2️⃣ Where Anomalies Occur in 5G Architecture

LayerExample Anomalies
RAN (gNB)PRB spikes, SINR drops, HO failures
TransportLatency, jitter, packet loss
5G Core (AMF/SMF/UPF)Session drops, CPU/memory leaks
Network SlicingSLA breach in one slice only
Edge / MECApp latency, resource starvation
Devices (UE/IoT)Misbehaving firmware, signaling storms

3️⃣ Key 5G KPIs Used for Anomaly Detection

🔹 RAN KPIs

  • PRB utilization (UL/DL)
  • SINR / RSRP / RSRQ
  • Handover success rate
  • Call drop rate
  • Cell availability

🔹 Core KPIs

  • Session setup success rate
  • PDU session latency
  • UPF throughput
  • NF CPU/memory

🔹 Slice KPIs

  • Slice latency
  • Slice packet loss
  • SLA violation %

1. Radio Access Network (RAN) KPIs

These detect radio degradation, interference, coverage holes, and mobility issues.

🔹 Signal & Quality

  • RSRP (Reference Signal Received Power)

    Anomaly: Sudden drop → coverage loss, antenna failure

  • RSRQ (Reference Signal Received Quality)

    Anomaly: Poor quality despite good power → interference or congestion

  • SINR (Signal-to-Interference-plus-Noise Ratio)

    Anomaly: Rapid fluctuation → interference, jamming, misconfiguration

🔹 Mobility

  • Handover Success Rate

    Anomaly: Increase in failures → neighbor cell issues

  • Ping-Pong Handovers

    Anomaly: Poor cell planning or unstable radio conditions

2. Traffic & Throughput KPIs

Used to detect congestion, abnormal usage, or throttling.

  • Uplink / Downlink Throughput
    • Sudden drop → congestion, scheduler issues
  • PRB (Physical Resource Block) Utilization
    • Sustained 90–100% → capacity bottleneck
  • Traffic Volume per Slice / APN
    • Unexpected spike → rogue device or misbehaving application

3. Latency & Reliability KPIs (Critical for URLLC)

Used heavily in industrial automation, robotics, and remote control.

  • End-to-End Latency
    • Spike beyond SLA → core/RAN processing delay
  • Jitter
    • High variance → packet scheduling issues
  • Packet Loss Rate
    • 1–2% → radio instability or buffer overflow

4. Core Network KPIs

Detect signaling storms, session failures, and control-plane anomalies.

  • Session Setup Success Rate (PDU Session)
    • Drop → AMF/SMF failures
  • Registration Success Rate
    • Sudden failures → authentication or slice issue
  • Control Plane Latency (AMF ↔ gNB)
    • Increase → transport or core congestion

5. Device & Subscriber KPIs

Used to detect faulty devices, misconfigured UEs, or security threats.

  • Attach / Detach Frequency
    • Excessive re-attaches → device instability
  • Idle-to-Connected Transition Failures
    • Radio or signaling issue
  • UE Power Consumption Patterns
    • Abnormal drain → signaling loops or retries

6. Network Slice KPIs (Very Important in Private 5G)

Used to detect slice SLA violations.

  • Slice Latency SLA Breach Rate
  • Slice Throughput Deviation
  • Slice Availability
  • Inter-slice Resource Starvation

Example:

Safety slice latency > 20 ms → critical anomaly

7. Transport / Backhaul KPIs

Detect fiber, IP, or switch-level failures.

  • Backhaul Latency
  • Packet Drops on UPF Interfaces
  • Link Utilization
  • Clock Sync Drift (PTP / TSN)

8. Security & Behavioral KPIs

Used for AI-driven anomaly & threat detection.

  • Signaling Rate per UE
    • Spike → signaling storm / DoS attempt
  • Unexpected Traffic Pattern
    • New protocol or destination → malware
  • Unauthorized Slice Access Attempts
  • IMEI / SIM Behavior Deviation

9. AI/ML-Derived Anomaly Indicators

These are not raw KPIs, but learned patterns:

  • KPI Baseline Deviation Score
  • Multivariate KPI Correlation Break
  • Time-Series Change Point Detection
  • UE / Cell Health Score
