Categories of Anomaly Detection in 5G Networks

1. By Network Domain

🔹 RAN Anomalies

  • PRB utilization spikes
  • SINR / RSRP degradation
  • Handover failures
  • Cell outage / flapping
  • Coverage holes

Example:

Sudden PRB spike in one gNB without traffic growth → interference

🔹 Transport Network Anomalies

  • Latency / jitter increase
  • Packet loss
  • Link congestion
  • Backhaul failures

Example:

Fiber micro-cut causing intermittent packet loss

🔹 5G Core Anomalies

  • AMF/SMF signaling storms
  • UPF throughput drop
  • NF CPU / memory leaks
  • Session setup failures

🔹 Network Slice Anomalies

  • Slice-specific SLA breach
  • Resource starvation
  • Cross-slice interference

🔹 Edge / MEC Anomalies

  • Application latency spikes
  • Edge compute overload
  • Service crashes

🔹 Device / UE Anomalies

  • Misbehaving IoT devices
  • Firmware bugs
  • Signaling floods

2. By Performance Impact Type

🔹 Capacity Anomalies

  • PRB saturation
  • CPU / memory exhaustion
  • Bandwidth bottlenecks

🔹 Quality Anomalies

  • Throughput drop
  • Latency increase
  • Packet loss
  • Jitter variation

🔹 Availability Anomalies

  • Cell down
  • NF instance crash
  • Slice outage

🔹 Reliability Anomalies

  • Frequent call drops
  • Session flapping
  • Intermittent failures

3. By Temporal Behavior

🔹 Point Anomalies

  • Sudden KPI spike or dip

Example:

Single sudden latency spike

🔹 Contextual Anomalies

  • Normal KPI but abnormal in context (time/location/slice)

Example:

High traffic at 3 AM in rural cell

🔹 Collective Anomalies

  • Group of KPIs together show abnormal pattern

Example:

PRB ↑ + SINR ↓ + Throughput ↓

4. By Data Type

🔹 KPI-based Anomalies

  • RAN, Core, Slice KPIs

🔹 Log-based Anomalies

  • Error bursts
  • Repeated warnings
  • New log patterns

🔹 Trace / Signaling Anomalies

  • Abnormal call flows
  • Excessive retries
  • Protocol violations

🔹 Alarm-based Anomalies

  • Correlated alarms across layers

5. By Detection Technique

🔹 Rule-based Anomalies

  • Threshold crossing
  • Policy violations

🔹 Statistical Anomalies

  • Moving average deviation
  • Seasonal mismatch

🔹 Machine Learning-based Anomalies

  • Isolation Forest
  • Autoencoders
  • LSTM
  • Clustering-based

🔹 AI / AIOps-based Anomalies

  • Multi-domain correlation
  • Explainable anomaly detection
  • NLP-based RCA

6. By Business / SLA Impact

🔹 Customer Experience (QoE) Anomalies

  • Video buffering
  • Call quality degradation
  • Gaming latency spikes

🔹 SLA / KPI Breach Anomalies

  • Enterprise slice SLA violation
  • URLLC reliability drop

🔹 Revenue-impacting Anomalies

  • Billing mismatches
  • Premium slice underperformance

7. By Security Nature

🔹 Signaling Anomalies

  • DoS attacks
  • Malformed packets

🔹 Access Anomalies

  • Unauthorized slice access
  • SIM misuse

🔹 Behavior-based Security Anomalies

  • UE behaving outside normal pattern

8. By Automation Readiness

🔹 Detect-only Anomalies

  • Informational alerts

🔹 Actionable Anomalies

  • Auto-scaling
  • Parameter tuning

🔹 Closed-loop Anomalies

  • Full self-healing without human intervention
