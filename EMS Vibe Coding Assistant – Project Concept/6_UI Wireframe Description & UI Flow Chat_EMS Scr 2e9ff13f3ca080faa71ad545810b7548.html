1. Design Principles

  • EMS-first UI: Assistant enhances EMS, does not replace it
  • Non-intrusive chat: Always visible, collapsible
  • Explain → Preview → Execute flow
  • Safety by design (read vs write visual cues)
  • Zero clutter for NOC usage

3. Key UI Components

3.1 EMS Main Canvas (Primary Area)

Displays:

  • KPI graphs & bar charts
  • Alarm tables (current / history)
  • Configuration editors
  • Node / Cell status panels

Behavior:

  • Reacts dynamically to chat commands
  • Highlights affected elements (nodes, cells)
  • Shows context-specific views based on chat intent

3.2 EMS Vibe Assistant – Chat Panel

Position: Bottom-right (dockable)

States:

  • Collapsed (icon only)
  • Expanded (30–40% width)
  • Full-screen (analysis mode)

Chat Elements

  • User message bubbles
  • AI explanation bubbles
  • Action cards (preview / approve)
  • Status badges (READ / WRITE / BLOCKED)

  • Large fonts for alarms
  • Minimal animation
