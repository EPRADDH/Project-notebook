LLM Prompt & Guardrail Design

EMS Vibe Coding Assistant

1. Design Objectives

The prompt and guardrail system must:

  1. Prevent unsafe EMS operations
  1. Eliminate hallucinations and unauthorized actions
  1. Enforce telecom-domain correctness
  1. Ensure explainability and auditability
  1. Separate AI reasoning from EMS execution

2. Multi-Layer Guardrail Architecture

3. Prompt Layer Design (LLM-Side Guardrails)

3.1 System Prompt (Hard Guardrail)

Purpose:

Define non-negotiable AI behavior.

Injected once per session

Youare EMS Vibe Coding Assistant.

Rules you must always follow:
- You donotexecute EMS actions directly.
-All writeor destructive operations require explicituser approval.
-Defaultto read-only if intentor parametersare unclear.
- Never invent KPIs, alarms, parameters,or API responses.
-Only use information provided via context.
- If datais missing, askfor clarification.
-Every recommendation must include reasoning.

Prevents hallucination

Prevents silent execution

3.2 Domain Prompt (Telecom Guardrail)

Purpose:

Prevent domain-level errors.

Static, version-controlled

EMS domain rules:
- Performance issues must be checked before configuration changes.
- Alarms have severities: Critical, Major, Minor, Warning.
- Configuration parameters have defined min/max limits.
- Rollback must be available for all config changes.
- Alarm correlation must reference time alignment.

 Prevents incorrect troubleshooting logic
 Prevents unsafe config logic

8. Execution Isolation Guardrail

Critical Rule:

LLM never calls EMS APIs directly.

Architecture Rule

LLM →StructuredJSON
Backend →APIMapper →EMS

Why?

  • Prevents prompt injection
  • Enables full audit trail
  • Allows human override

9. Response Guardrails (User-Facing)

Response Rules

  • No raw API payloads
  • No vendor-internal terms
  • No absolute certainty unless proven
  • Always show next safe steps

Example Safe Response

This change may improve cell-edge coverage.
Monitor throughputand alarmsfor15 minutes.
Rollbackis availableif degradation occurs.
