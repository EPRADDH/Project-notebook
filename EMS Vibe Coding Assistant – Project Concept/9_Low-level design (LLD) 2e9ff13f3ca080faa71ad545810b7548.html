Low-Level Design (LLD)

1. Scope of This LLD

This document covers:

  • Service-level decomposition
  • Detailed component responsibilities
  • API contracts
  • Data models
  • Prompt orchestration logic
  • Guardrail enforcement
  • Error handling & logging

Out of scope:

  • Vendor-specific EMS APIs (abstracted)
  • UI pixel-level mockups

3.5 Intent Classifier

Output Schema

{
"intent":"CONFIG_PREVIEW",
"target":"Node-12",
"parameters":{
"tx_power":"+2dB"
},
"confidence":0.92
}

Rules

  • confidence < 0.7 → clarification request
  • unknown intent → READ_ONLY fallback
